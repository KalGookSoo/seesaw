# 내 활동 이력

현재 사이트에 대한 권한과 카테고리 읽기 권한을 확인한 후 노출 중인 게시글·댓글만 조회한다. 삭제되거나 접근할 수 없게 된 콘텐츠는 결과에서 제외한다. 좋아요는 현재 승인된 Vote만 조회하며 게시글과 댓글의 참조 식별자를 확인한다. 좋아요를 취소하면 해당 Vote가 삭제되어 목록에서도 사라진다.

`GET /api/me/activity/{articles|replies|likes}`는 `siteId`, `page`, `size`를 받는다. 사용자 식별자는 인증 정보에서 가져오며, 결과는 작성일과 ID 내림차순으로 정렬한다. 목록의 전체 건수를 재사용할 수 있으므로 별도 요약 집계 API는 두지 않는다. 요약 카드가 필요해질 때 요청 수와 집계 비용을 검토한다.

## 일정 참여와 투표 검토

일정 참석자는 현재 `Attendee`의 이메일, 이름, 역할, 참석 상태로 저장된다. 이 정보에는 로그인 계정을 식별하는 사용자 ID가 없으므로 이메일이 일치한다는 이유만으로 다른 사람의 일정 참여 이력을 연결하지 않는다. 활동 이력에 일정을 추가하려면 참석자와 계정의 검증된 연결, 사이트별 권한, 참석 취소 및 일정 삭제 정책을 먼저 정하고 이에 맞는 모델과 조회 API를 별도로 구현해야 한다. 현재 Vote는 게시글·댓글의 좋아요에 사용되므로 일정 참여로 해석하지 않는다.
